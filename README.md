# Kindle PageBridge · 蓝牙翻页器

面向已越狱 Kindle Paperwhite 5 的 KUAL 插件。在 Kindle 上完成蓝牙配对、设备选择和按键学习，让原生阅读器、KOReader 和 Kindle 微信读书共用一套触摸翻页方式。

当前下载：**0.3.0-rc1-enc1 minimal**，核心程序采用启动时解密封装。安装 ZIP 内只保留运行文件、安装校验和必要许可，操作说明放在本页。

## 使用前提与验证范围

- 已越狱、已安装 KUAL 的 **PW5，固件 5.17.1.0.3**；安装器会检查系统 Mesquite 设置环境与 UHID 支持，其他型号、固件暂不放行。安装需要至少 80 MB 空闲空间用于暂存。
- 实物遥控器目前为 **绿联 UGREEN LP998**。其他标准蓝牙 HID 翻页器可尝试学习，是否可用需要逐型号确认；私有 BLE 协议不保证兼容。
- 未加密的统一触摸方案已在原生阅读器、KOReader、微信读书的默认竖屏正文中实测；旧版 KUAL 设置、学习和恢复流程也有 PW5 验证记录。**本次 enc1 加密启动器只完成电脑端验证，尚未在 Kindle 实机验收，当前按预发布版提供。**
- 没有严格的续航对比，不承诺具体省电幅度。

## 第一次安装

1. 下载上方完整包，在电脑解压。
2. 用 USB 连接 Kindle，把解压得到的 `extensions` 文件夹**合并复制**到 Kindle 磁盘根目录，也就是能看到 `documents` 的那一层；保留原目录中的其他插件。
3. 安全弹出 Kindle，打开 KUAL。必要时退出再进入 KUAL 刷新菜单。
4. 进入 **蓝牙翻页器 → 打开设置（首次使用从这里开始）**。首次会自动安装，也可先进入“安装与维护 → 安装 / 更新”。首次启动蓝牙可能需要等待几十秒。

## 配对翻页器

1. 给翻页器充电，先断开它与手机等其他设备的连接。
2. 按该型号的说明书进入配对模式。不同设备的配对按法不同，没有通用的长按组合。
3. 在设置页第 1 步点击 **搜索附近设备**，找到自己的设备后点 **配对**。
4. 配对完成后，必要时轻按一次唤醒翻页器，再点 **刷新已配对设备 → 连接**。

已配对、已连接的设备直接继续，无需每天重新配对。请在插件设置页完成配对与连接。

## 选择设备并学习按键

1. 在第 2 步点 **刷新输入设备**，选择自己的遥控器。
2. 确认它是专门用于翻页的接口，勾选 **这个接口专门用于翻页，允许接管其输入**，再点 **使用并学习按键**。若同一接口还用于打字或控制鼠标，请不要接管；组合设备选择专用翻页接口。LP998 也可以使用预设。
3. 点 **学习下一页**，将同一个按键完整**按下、松开两次**，页面确认后点 **保存学习结果**。
4. 点 **学习上一页**，用另一个按键重复两次并保存；划动式设备执行两次相同的完整划动。
5. 确认 **翻页已开启**，点 **完成，返回主页**，打开阅读器的一本书，在正文试前后翻页。

学习期间不翻页；每轮默认 60 秒，超时后点“重新学习”或“取消并恢复翻页”。保存立即生效。前后方向反了可点“交换前后方向”；单键设备可选“只用下一页”。

## 三个阅读器如何工作

插件将学习后的下一页、上一页动作变成系统触摸事件，当前阅读器接收点击并翻页。默认下一页点击右侧中部 `(85%, 50%)`，上一页点击左侧中部 `(15%, 50%)`，三个阅读器共用一套位置。

横屏、自定义触区或方向不同，在“进阶设置”中调整坐标和旋转，再保存并在正文验证。它不会自动识别当前阅读器、正文或菜单，**进入菜单、书库前先关闭翻页，避免遥控器误点按钮。**系统休眠期间跳过翻页输出。

## 日常操作、更新和卸载

- **重连：**轻按唤醒翻页器；仍不通时打开设置，刷新已配对设备并点连接。
- **暂停：**在设置页点“关闭翻页”，保留配对和映射。
- **开机后：**默认不开机自启；可从 KUAL 开启翻页服务。自启选项位于“安装与维护”，检测到已知旧 DSH 自启方案时会拒绝同时启用。
- **更新：**合并复制新版包的 `extensions`，进入 KUAL → 蓝牙翻页器 → 安装与维护 → 安装 / 更新，之后重新打开设置；配置与配对保留。依赖不齐时使用完整包。
- **停用：**KUAL → 蓝牙翻页器 → 停用并恢复原方案。
- **卸载：**KUAL → 蓝牙翻页器 → 安装与维护 → 卸载插件 → 确认卸载并恢复原方案。保留的自身映射及蓝牙备份位于 Kindle 的 `pagebridge` 文件夹，不删除书籍或原有阅读器。

蓝牙服务接管蓝牙时，原生蓝牙音频可能无法同时使用。设置保存不需要重启阅读器。
